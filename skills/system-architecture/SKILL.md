# 시스템 아키텍처

요구사항을 구현 구조로 변환할 때 이 스킬을 사용합니다.

## 산출물

- 아키텍처 문서
- 기술 결정사항
- 연동 경계
- 환경 구성안
- 배포 구조

## 작업 절차

1. 요구사항, 비기능 요구사항, IA, 운영 제약을 확인합니다.
2. 논리 아키텍처와 물리 아키텍처를 정의합니다.
3. 기술 선택의 이유와 트레이드오프를 기록합니다.
4. 연동, 데이터, 배포 경계를 식별합니다.
5. 아키텍처 결정사항을 안정적인 산출물로 남깁니다.
