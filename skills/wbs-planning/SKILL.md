# WBS 계획

프로젝트 범위를 실행 가능한 작업 단위로 나눌 때 이 스킬을 사용합니다.

## 산출물

- 마일스톤 목록
- 작업 패키지 표
- 의존성 맵
- 담당자 맵
- 일정 및 납기 리스크

## 작업 절차

1. 요구사항, 제약사항, 목표 일정을 확인합니다.
2. 작업을 단계별 패키지로 분해합니다.
3. 각 작업의 산출물과 완료 기준을 정의합니다.
4. 의존성과 critical path 리스크를 식별합니다.
5. WBS 산출물과 프로젝트 상태를 갱신합니다.
