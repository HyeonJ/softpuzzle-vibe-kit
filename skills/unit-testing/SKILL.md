# 단위테스트

독립적으로 검증 가능한 동작을 구현 중이거나 구현한 뒤 이 스킬을 사용합니다.

## 산출물

- 단위 테스트 케이스
- 커버리지 메모
- 예외 케이스 목록
- 테스트 명령 결과

## 작업 절차

1. 독립적으로 테스트할 수 있는 동작을 식별합니다.
2. 정상, 경계, 실패 경로를 다룹니다.
3. 기존 테스트 프레임워크와 로컬 패턴을 사용합니다.
4. 읽기 쉽고 안정적인 테스트를 작성합니다.
5. 실행 명령과 결과를 기록합니다.
