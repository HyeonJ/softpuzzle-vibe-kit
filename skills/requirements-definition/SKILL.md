# 요구사항 정의

IA, 디자인, 아키텍처, 개발 작업을 시작하기 전에 이 스킬을 사용합니다.

## 산출물

- 비즈니스 요구사항
- 기능 요구사항
- 비기능 요구사항
- 인수 기준
- 오픈 이슈 목록

## 작업 절차

1. 프로젝트 브리프와 이해관계자 메모를 확인합니다.
2. 결정사항과 가정을 분리합니다.
3. 안정적인 ID를 붙여 요구사항을 작성합니다.
4. 테스트 가능한 인수 기준을 추가합니다.
5. 확정되지 않은 내용은 요구사항으로 단정하지 말고 오픈 이슈로 남깁니다.
