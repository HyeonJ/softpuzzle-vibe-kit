# 보안 및 성능

비기능 요구사항을 설계하거나 검토할 때 이 스킬을 사용합니다.

## 산출물

- 보안 체크리스트
- 성능 목표
- 개인정보 및 데이터 보호 메모
- 로깅과 모니터링 요구사항
- 리스크 등록 내용

## 작업 절차

1. 민감 데이터와 보호가 필요한 작업을 식별합니다.
2. 인증, 권한, 검증, 암호화, 감사 요건을 정의합니다.
3. 성능 예산과 확장성 가정을 정의합니다.
4. 모니터링, 알림, 로깅 요구사항을 추가합니다.
5. 리스크와 검증 방법을 기록합니다.
