# IA 및 화면 계획

요구사항이 화면과 사용자 흐름으로 정리될 수 있을 만큼 안정되었을 때 이 스킬을 사용합니다.

## 산출물

- 내비게이션 구조
- 사용자 흐름
- 화면 목록
- 라우트 맵
- 요구사항별 화면 매핑

## 작업 절차

1. 요구사항과 사용자 역할을 확인합니다.
2. 기능을 내비게이션 영역으로 묶습니다.
3. 주요 흐름과 화면 목록을 정의합니다.
4. 각 화면을 원천 요구사항에 연결합니다.
5. 디자인과 구현에 넘길 화면정의서 초안을 준비합니다.
