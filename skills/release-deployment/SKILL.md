# 운영배포

스테이징 또는 운영 배포 전에 이 스킬을 사용합니다.

## 산출물

- 배포 체크리스트
- 릴리즈 노트
- 롤백 계획
- 모니터링 계획
- 운영 인수인계 메모

## 작업 절차

1. 빌드, 테스트, 마이그레이션, 보안 준비 상태를 확인합니다.
2. 환경 설정과 배포 절차를 검토합니다.
3. 릴리즈 노트와 롤백 계획을 준비합니다.
4. 모니터링과 알림 담당자를 확인합니다.
5. 배포 결정과 잔여 리스크를 기록합니다.
