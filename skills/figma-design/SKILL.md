# Figma 디자인

디자인 생성, Figma 검토, 디자인-개발 인수인계가 필요할 때 이 스킬을 사용합니다.

## 산출물

- 디자인 검토 메모
- 컴포넌트 매핑
- 접근성 이슈
- 반응형 동작 메모
- 디자인-개발 인수인계 체크리스트

## 작업 절차

1. 화면정의서와 디자인 시스템 규칙을 확인합니다.
2. 새 컴포넌트를 만들기 전에 기존 Figma 라이브러리를 확인합니다.
3. 가능한 경우 디자인 시스템 컴포넌트를 우선 사용합니다.
4. 간격, 타이포그래피, 대비, 상태, 반응형 동작을 검토합니다.
5. 퍼블리싱과 프론트 개발에 필요한 구현 메모를 남깁니다.
