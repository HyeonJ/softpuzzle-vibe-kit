# 개발환경

구현 작업을 시작하기 전에 개발자가 같은 방식으로 실행하고 검증할 수 있도록 이 스킬을 사용합니다.

## 산출물

- 개발환경 세팅 가이드
- 환경 변수 목록
- 로컬 실행 명령
- 품질 게이트 명령
- 저장소 작업 규칙

## 작업 절차

1. 저장소와 패키지 도구를 확인합니다.
2. 필요한 런타임, 서비스, 시크릿을 식별합니다.
3. 로컬 세팅과 검증 명령을 정의합니다.
4. 프로젝트 스택에 맞는 경우에만 누락된 스크립트를 추가합니다.
5. 실행 가능한 명령을 프로젝트 상태에 기록합니다.
