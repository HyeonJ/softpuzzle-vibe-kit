# 통합테스트

동작이 모듈, API, DB, 브라우저 경계를 넘을 때 이 스킬을 사용합니다.

## 산출물

- 통합 테스트 시나리오
- 테스트 데이터 요구사항
- 환경 요구사항
- 테스트 명령 결과
- 결함 메모

## 작업 절차

1. 여러 컴포넌트가 함께 동작해야 하는 흐름을 식별합니다.
2. 준비, 데이터, 실행, 기대 결과를 정의합니다.
3. 기존 통합 테스트 또는 e2e 테스트 도구를 사용합니다.
4. 현실적인 성공 경로와 실패 경로를 검증합니다.
5. 결함과 잔여 리스크를 기록합니다.
