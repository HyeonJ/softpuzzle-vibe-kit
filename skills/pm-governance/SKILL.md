# PM 거버넌스

프로젝트를 착수하거나 운영 기준을 정리할 때 이 스킬을 사용합니다.

## 산출물

- 프로젝트 조직도
- R&R 매트릭스
- 거버넌스 규칙
- 의사결정 로그
- 리스크 로그
- 산출물 인덱스

## 작업 절차

1. 프로젝트 브리프와 현재 프로젝트 상태를 확인합니다.
2. 이해관계자, 담당자, 승인자, 참여자를 식별합니다.
3. 커뮤니케이션 주기와 의사결정 규칙을 정의합니다.
4. PM 산출물을 만들거나 갱신합니다.
5. 오픈 이슈와 리스크를 기록합니다.
