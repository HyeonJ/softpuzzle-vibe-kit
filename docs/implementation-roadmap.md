# 구현 로드맵

## 1단계: 기본 골격

- 플러그인 manifest와 폴더 구조를 만듭니다.
- 단계별 스킬 초안을 추가합니다.
- 표준 산출물 템플릿을 추가합니다.
- 역할 정의를 추가합니다.
- 프로젝트 상태와 인수인계 규칙을 정의합니다.

## 2단계: 문서 워크플로우

- PM setup, WBS, 요구사항, IA, 화면정의 스킬을 구체화합니다.
- 템플릿에서 프로젝트 산출물 폴더를 생성하는 스크립트를 추가합니다.
- 산출물 품질 검토 체크리스트를 추가합니다.

## 3단계: 디자인 워크플로우

- Figma 연동 가이드를 추가합니다.
- 디자인 시스템 검색과 컴포넌트 매핑 규칙을 추가합니다.
- 화면 검토와 접근성 검토 절차를 추가합니다.

## 4단계: 개발 워크플로우

- 아키텍처, DB, API, 프론트, 테스트 스킬을 구체화합니다.
- 저장소 초기 세팅 스크립트를 추가합니다.
- lint, test, build, dependency review 같은 품질 게이트를 추가합니다.

## 5단계: 릴리즈 워크플로우

- 배포 준비 체크를 추가합니다.
- 릴리즈 노트와 롤백 템플릿을 추가합니다.
- 모니터링과 운영 인수인계 템플릿을 추가합니다.

## 6단계: 마켓플레이스 준비

- 플러그인 메타데이터를 확정합니다.
- 예시와 스크린샷을 추가합니다.
- 스킬 이름, 범위, 문서를 검증합니다.
- 버전 정책과 호환성 notes를 추가합니다.
